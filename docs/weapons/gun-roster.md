# Gun roster: DRAFT v2

**Status (2026-10-27):** v1 was reviewed by the developer. v2 adds the guns they asked for: 4 more pistols, 4 more revolvers, 3 more SMGs, 2 more shotguns, 2 more military sniper rifles and an AK-47. **The developer set how many to add; Claude picked which models (marked *new*), so swap any freely.**
Decided so far: the machine gun and the .50 cal are in the top rarity tier; .357 guns also take .38; smuggled guns come from the port container yards (GDD §12). Still open: final sign-off on the list.

Rules this follows (GDD §12–13): a vast selection; guns rare in NYC (mainly police and military, very rarely in homes); fictional in-game names; guns grouped by **platform** so guns on the same platform share animations and rails.
The "Based on" column is an internal reference only. Every gun gets a fictional name in the game.

## New loot sources this list adds (for the map)
- **Port container yards:** smuggled guns (AK family, Saiga-12, Uzi, MAC-10, Scorpion, Vector). **Decided** (GDD §12): mainly a customs holding warehouse, sometimes hidden in containers found via manifests; all four ports are in.
- **Police ESU** (special units) and **federal sites**: SMGs, short rifles, full-auto pistol, USP.
- **Gun shop:** one or two in the whole map (NYC has very few), so each is a hotspot.
- **Marinas, construction sites, schools:** the oddities.
